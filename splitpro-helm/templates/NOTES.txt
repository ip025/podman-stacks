SplitPro has been deployed.

1. Ensure the required Secret exists and contains at least POSTGRES_PASSWORD and
   NEXTAUTH_SECRET (keys must match the env var names):

     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.existingSecret | default "<splitpro-secrets>" }} \
       --from-literal=POSTGRES_PASSWORD='...' \
       --from-literal=NEXTAUTH_SECRET='...'

2. The external PostgreSQL database must be reachable at
   {{ .Values.externalDatabase.host | default "<externalDatabase.host>" }}:{{ .Values.externalDatabase.port }}.
   Recurring transactions require the pg_cron extension to be installed there.

3. Set config.NEXTAUTH_URL to the URL users will access, then get the service:

     kubectl -n {{ .Release.Namespace }} get svc {{ include "splitpro.fullname" . }}

{{- if not .Values.ingress.enabled }}

Ingress is disabled. Enable it via ingress.enabled=true (and set ingress.className,
hosts and annotations) or port-forward locally:

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "splitpro.fullname" . }} 3000:{{ .Values.service.port }}
{{- end }}
